# 机器学习范式梳理（2026-07-29）

> 本文是我上午学深度学习的归纳。带「阿布纠正」的部分是我原话里的概念混淆，由学习搭子阿布直接指出并修正——这部分最值得反复看。

## 一、我原以为的（上午自学版本）

1. **监督学习 vs 无监督学习**：无监督学习是「从已有数据里形成 structure，再用这个 structure 去解某些 task」。
2. **生成式（我口误成 "Answerized"，应为 generative / autoregressive）**：用 latent variables 在数据（词、文本、图像）之间找 hidden structure，能生成多样且真实的输出。
3. **自监督 = 监督 + 无监督结合**：既能解决已知问题，又能发现 material 之间的 hidden structure 并生成新输出。
4. **强化学习**：用一套 reward / penalty 系统评估 LLM 的行为，让它预测 / 生成得更好。

## 二、阿布纠正（重要，按顺序看）

### 纠正 1：「无监督 vs 生成」这个对立是错的

- 我说的「无监督 = 形成结构去解 task」本质是 **判别式**（聚类、降维、学 P(y|x) 的边界）。
- 我说的「生成 = 用隐变量找隐藏结构、产出新东西」是 **生成式**（VAE / GAN / 自回归，学整个数据分布 P(x)）。
- 这俩**不是「无监督 vs 生成」**，而是**同一条轴的两端：判别式 vs 生成式**。
- 而且生成式模型绝大多数就是用无监督 / 自监督训练的——它俩是亲戚，不是对立阵营。

### 纠正 2：自监督不是「监督 + 无监督拼起来」

- 它是一种**用数据自身造标签**的训练策略，不从人那拿标签。
- BERT：盖住一个词让模型猜；GPT：让模型猜下一个词。标签来自文本自己。
- 预训练后得到的表征**既擅长理解（BERT 那路）又擅长生成（GPT 那路）**——所以「既有解决问题能力、又有生成能力」的直觉是对的，但机制是「造标签」，不是「缝合两种范式」。

### 纠正 3：强化学习（这段我理解对了，阿布确认）

- RLHF 用 reward / penalty 当**代理信号**去调 LLM 的生成。
- 基础能力来自自监督预训练，RL 是后处理的打磨（polish），不是能力来源。

## 三、落到 LLM 的完整链路

```
自监督预训练（BERT 理解 + GPT 生成）打底，得到通用表征
        ↓
RLHF / RLAIF 用奖励模型对齐人类偏好 → 让生成更符合预期
```

一句话：**自监督给能力，强化学习给方向。**

## 四、概念速查表

| 范式 | 标签来源 | 学什么 | 代表 |
|------|---------|--------|------|
| 监督学习 | 人工标注 y | P(y\|x) | 分类 / 回归 |
| 无监督学习 | 无标签 | 数据结构 | 聚类 / 降维 |
| 判别式 | 无标签 | P(y\|x) 决策边界 | 逻辑回归 |
| 生成式 | 无标签 | P(x) 数据分布 | VAE / GAN / 自回归 |
| 自监督 | 数据自身造 | 通用表征 | BERT / GPT |
| 强化学习 | 奖励信号 | 策略（policy） | RLHF |
