### 第 1 题

- 参考答案：项目是干什么的（What）；为什么有用（Why）；如何开始使用（How）
- 常见误区：只记名词，不说明它解决什么问题。
- 误区产生原因：复习时只背定义，没有把概念和用途绑定起来。
- 正确判断线索：回答时至少补一句“它解决什么问题”。

### 第 2 题

- 参考答案：GitHub 会自动识别以下位置的 README： 优先级： 如果三个地方都有 README： 会被优先显示
- 常见误区：把相近概念、步骤或角色混在一起。
- 误区产生原因：看到关键词相似，就忽略了输入输出或职责边界。
- 正确判断线索：先问自己：这一步的输入、输出和责任分别是什么？

### 第 3 题

- 参考答案：GitHub 会显示 README， 但超过： 的部分会被截断（truncated）；所以 README 应该保持简洁
- 常见误区：背了结论，但不会落到实际调用或流程里。
- 误区产生原因：只停留在抽象定义，没有顺着真实使用场景走一遍。
- 正确判断线索：把答案改写成“遇到什么场景就怎么用”的句式。
