## 上午（L2 深度学习 · 线性回归 / loss / 生成式 vs 判别式）

### 学了什么
- **线性回归**：用线性假设拟合数据，目标是找到让预测最接近真实的参数。
- **loss vs cost（用户已分清，准确）**：
  - loss = **单个样本**的预测与真实之间的差距（如平方误差）。
  - cost = 所有样本 loss 的**平均** + **与单个样本无关的附加项**（正则化，如权重衰减）。
  - 用户原话："cost function has additional terms not associated with individual data points" —— 指的就是正则化项，准确。
- **生成式 vs 判别式（用户归纳基本对）**：
  - 判别式：给定 X，求 y —— 直接建模 P(y|X)。
  - 生成式：学联合分布，能回答"X 是如何由 y 产生的" —— 建模 P(X, y)，由此可推 P(y|X)（预测）与 P(X|y)（生成）。
- **科学建模类比（用户的洞察，已订正术语）**：科学家有**假设（hypothesis，口述误为 face）**和测量，用模型度量世界，找"模型与世界之间的 loss function"，再证明模型有用、能生成或预测。

### Agent 订正（精度）
- loss 精确措辞：衡量**模型预测 ŷ** 与**真实标签 y** 的差距（"reality"=真实标签，不是"真实世界本身"）。
- 生成式"know how X arises from y" 精确为：学到联合 P(X,y) 后，可求 P(X|y)（给定类别生成样本）与 P(y|X)（预测）。判别式只建模 P(y|X)，不能反推 P(X|y)。
- 例子补充：判别式（逻辑回归、SVM、多数神经网络分类器）；生成式（朴素贝叶斯、高斯混合、扩散模型、GAN、LLM 本质是建模 token 联合分布）。

### 与年度目标的连接
- 这是你 L2「Transformer/训练流程/建模」地基的第一块。loss/cost 区分 + 生成式/判别式，直接对应你年目标的"理解训练流程"与"熟悉 LLM（生成式）架构"。
- 科学建模类比很漂亮：你这套"假设→测量→loss→验证→生成/预测"正是研究者工作方式，吻合你年度北极星"提出问题→学习→实验→构建→反馈→迭代"。

  1. **感知用户状态**：Agent 要能知道用户当前处于什么状态（学到哪、卡在哪、状态如何）。
