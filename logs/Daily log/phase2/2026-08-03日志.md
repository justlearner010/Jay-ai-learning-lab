## 上午（L2 深度学习 · 线性回归 / loss / 生成式 vs 判别式）

线性回归就是用线性假设去拟合数据，目标是找到让预测最接近真实的参数。

loss 和 cost 你分得很清，而且准确：loss 是单个样本的预测和真实之间的差距（比如平方误差）；cost 是所有样本 loss 的平均，再加一个和单个样本无关的附加项（正则化，比如权重衰减）。你原话"cost function has additional terms not associated with individual data points"指的就是正则化项，对。

生成式和判别式你的归纳基本对：判别式给定 X 求 y，直接建模 P(y|X)；生成式学联合分布，能回答"X 是怎么由 y 产生的"，建模 P(X, y)，由此能推 P(y|X)（预测）和 P(X|y)（生成）。

你那个科学建模类比挺好（口述把 hypothesis 说成了 face，已订正）：科学家有假设和测量，用模型度量世界，找"模型与世界之间的 loss function"，再证明模型有用、能生成或预测。

补几个精确措辞：loss 衡量的是模型预测 ŷ 和真实标签 y 的差距（"reality"指真实标签，不是真实世界本身）。生成式学到联合 P(X,y) 后，能求 P(X|y)（给定类别生成样本）和 P(y|X)（预测）；判别式只建模 P(y|X)，反推不了 P(X|y)。例子：判别式有逻辑回归、SVM、多数神经网络分类器；生成式有朴素贝叶斯、高斯混合、扩散模型、GAN，LLM 本质也是在建模 token 联合分布。

这是你 L2（Transformer / 训练流程 / 建模）地基的第一块。loss/cost 区分加生成式/判别式，直接对应年目标里的"理解训练流程"和"熟悉 LLM（生成式）架构"。你那套"假设→测量→loss→验证→生成/预测"正是研究者的工作方式，也吻合你年度北极星"提出问题→学习→实验→构建→反馈→迭代"。

聊下来的要点：
1. 感知用户状态：Agent 得知道用户现在什么状态，学到哪、卡在哪。
