## 收尾（L2 真门 · 逐行讲清 闭环）

### 口述自证（3 问，18:20）
- **Q1 为什么非线性必须激活函数？** 叠 Linear 层本质还是线性变换——W₃(W₂(W₁x)) 退化成单个矩阵 (W₃W₂W₁)x，只能拟合直线。靠 ReLU/sigmoid 这类**非线性激活插在层间**，网络才能逼近曲线。→ ✅ 正确
- **Q2 autograd 算什么？** 自动求导（反向模式自动微分）：前向时建好计算图，再从 loss 沿**链式法则**往回把每个参数的梯度 ∂L/∂w 算出来。→ ✅ 正确
- **Q3 优化器拿梯度干啥？** 梯度方向是 loss 上升最快的方向，优化器就沿**负梯度**把参数挪一步（`w ← w − lr·∇w`），让 loss 下降。他口述"梯度方向决定优化方向"即此意，补一句更新式即完整。→ ✅ 正确

## 晚间（L4 复习 / 电容器）

### 做了什么
- 强化了**电容器**这块知识，重点厘清两组易混关系：
  - **定义式 vs 计算式（决定式）**：
    - 定义式 `C = Q/V` 是电容的"定义/量度"——对任何电容器都成立，表示 Q 与 V 成正比、比值恒定；它**不**意味着 C 由 Q 或 V 决定。
    - 计算式（决定式）由电容器本身结构决定，如平行板 `C = εS/d`、圆柱/球形各有一套——说明 C 是电容器**固有属性**，只与 ε、几何尺寸、介质有关，与 Q、V 无关。
    - 二者关系：定义式回答"电容是什么、怎么测"，计算式回答"电容由什么决定"；定义式可进一步推出储能式。
  - **电容器储能与 Q、C、V 的关系**：
    - 储能 `U = ½CV² = ½QV = Q²/(2C)`。三者可互换，因为 C=Q/V 把 Q 与 V 联系着。
    - 推导直觉：充电时第 q 库仑电荷入板所需电压是 q/C，做微元功 dW=(q/C)dq，从 0 积到 Q 得 `W=∫₀ᴼ (q/C)dq = Q²/(2C)`。
    - （注：单个电荷 q 在电势 V 处的电势能是 qV；电容器"储能"是全部电荷共同贡献的 ½QV，差那个 ½ 正是因为电压随充电从 0 升到 V。）
