## 晚间（L2 / 设计 own 最小 mini-agent · 五层架构）

### 做了什么
- 与 Codex 一步步讨论，**设计自己的最小 mini-agent**，拆成五层：
  1. **LLM 层（provider）**：只提供模型服务，屏蔽具体模型。
  2. **Agent 层**：含 **agent loop**——把 prompt 转成任务、执行、再循环；**决定何时调用工具**。
  3. **Tool 层**：agent 实际调用的具体 functions；**Agent 层定"何时"，Tool 层定"具体功能"**。
  4. **CLI 层**：把各层**粘合**起来，承载完整数据流动（用户输入 prompt → 转化为数据）；含文件解释等。
  5. **独立 TUI 层**：终端 UI，让 agent 在真实场景里被实际使用。
- **实施策略（重要）**：先分几个大文件、把每个文件的**依赖关系**定好，**具体的函数设计之后再做**——因为语法不用自己一个个敲，需要的是**知道数据流动**。
- **核心反思**：以前让 Agent/工具直接生成 = 失去对细节掌控 = "两眼瞎"；现在要自己掌控架构与数据流。
- **引出缺口**：agent 的**评估**还要学——要让产出"可直接使用"且"错误案例覆盖周到"。
