## 下午（L3 计算机基础 / CSAPP · 浮点表示 IEEE 754）

### 学了什么
- 浮点数的二进制布局：32-bit = **1 位 sign + 8 位 exponent + 23 位 fraction**；64-bit（double）= 1 + 11 + 52。sign 管正负，exponent 管"数量级/缩放"，fraction 管精度。
- 特殊值的判定（看 exponent 字段是否全 0 / 全 1）：

| 情形 | exponent 字段 | fraction | 数值含义 |
| --- | --- | --- | --- |
| Normalized 规格化 | 既非全0也非全1 | 任意 | (-1)^s × (1+frac) × 2^(e−bias)，隐含前导1 |
| Denormalized 非规格化 | 全 0 | 非 0 | (-1)^s × (0+frac) × 2^(1−bias)，无隐含前导1，平滑过渡到0 |
| ±0 | 全 0 | 全 0 | 0 |
| ±∞ | 全 1 | 全 0 | 溢出 / 除以0 |
| NaN | 全 1 | 非 0 | 不是一个数（如 0/0、∞−∞） |

> 注：NaN 的"全1"指的是 **exponent 字段全1**（sign 位 0/1 都行），不是 sign 位。

## 晚上（L4 数理 / 物理 · 电磁学重温）

### 学了什么
- 重温库仑定律，重新推导了**均匀带电杆（line charge）的电场强度**：对杆上电荷元沿杆积分，得到轴上某点的 E。标准结果（点 P 距杆中心 d）：`E = (1/4πε₀) · Q / (d² − (L/2)²)`，方向沿杆轴、背离带电杆（正电荷）。
- 极限检验：当 **L ≪ d** 时式子 ≈ `Q/(4πε₀ d²)`，即退化为**点电荷**——和你"远处把杆看成点电荷"的直觉一致。
- 口述里的 "四派一普S1/0" = `1/(4πε₀)`，即库仑常数形式，正确。
