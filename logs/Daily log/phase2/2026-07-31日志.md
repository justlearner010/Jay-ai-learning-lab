- 概念纠正（小）：你说的「loss function 和 reality 之间的 difference」——准确说法是 **loss function 本身是衡量「预测值 vs 真实标签（ground truth）」差距的函数**；它算出来的 loss 值才反映预测与真实的差距。loss function 不是和 reality 比较的「对象」，而是度量「差距」的「工具」。训练的本质就是靠这个差距反馈去调参数（反向传播）。
- 「通过图片学英语」是 comprehensible input 的延伸——用视觉语境替代听觉语境来推断词义，原理一致：靠可理解的语境而非硬背。
