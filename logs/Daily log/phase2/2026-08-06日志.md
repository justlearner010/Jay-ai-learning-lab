## 下午（L1 框架 / Pi Agent 架构深化 + 设计模式）

### 学了什么
- 从昨天三层架构（Pi-AI / loop / CLI·SDK）+ 独立 TUI 继续深化，今天看清了层间关系：
  - 单向依赖：上层依赖下层，而且上层看不到上一级发生了什么。Pi-AI 在最底，loop 在中间，CLI/SDK 在最上；CLI/SDK 只调 loop 暴露的接口，loop 只调 Pi-AI 暴露的接口，彼此不越级、不回看。
  - 每层只认下一层的契约，这是干净分层架构的样子：可替换、可测试、对上层透明。
- 看到一个很好的设计：type.ts 集中放跨文件共用的 type / interface。演进路径是先在单个文件里定义类型，多文件需要时就 import，最后抽到 type.ts 作为对外暴露的接口层。
  - 这个模式值得以后写大项目时借鉴：类型先局部、后集中，既能避免一开始过度设计，也避免类型散落难维护。

### 推导了什么
- 把电势和电场的方向关系彻底理顺了：电场 E 指向电势降低最快的方向，大小就是电势梯度的负值，E = −∇V。8/3 那次是从电场推到电势，今晚反过来把方向关系钉死，正负号、方向、大小三者对得上。
