# NumPy Transformer 基础学习设计

## 目标

在两周内通过“理论 → Lab → 独立 demo → 复盘”的闭环，扎实理解单层、单头 Transformer 的核心机制。目标是机制理解和独立排错能力，不是尽快拼出 RAG 或套用框架。

## 学习闭环

```text
课程与推导
  → 无答案的机制 Lab
  → hidden autograder 反馈失败类别
  → 不看答案独立实现小 demo
  → 复盘后决定是否进入更大项目
```

每个阶段必须留下可检查证据。Lab 只提供函数签名、输入输出契约、shape 约束、少量冒烟测试与分层提示；隐藏测试的输入和期望输出不对学习者公开。评分器报告错误属于数值稳定性、shape、mask、组合顺序或边界处理中的哪一类，并给出相应思考问题，但不泄露答案。

## 范围与非目标

首轮范围：token 向量、Q/K/V、缩放点积 attention、causal mask、单头 self-attention、LayerNorm、FFN、残差连接、单层 Transformer block，以及极小字符级 next-token prediction demo。

明确不做：multi-head attention、性能优化、外部模型框架、RAG、大数据集或生产级项目。

## 两周任务包与注意力分配

**重要程度：P0 = 必须吃透；P1 = 本轮必须完成；P2 = 只理解用途。**  
**难度：1 = 入门；2 = 基础推导；3 = 易出现 shape/数值错误；4 = 多机制整合。**

### 第 1 周：理论与机制 Lab（P0）

| 关卡 | 理论与实现主题 | 重要程度 / 难度 | 通过证据 |
| --- | --- | --- | --- |
| 0 | shape、矩阵乘法和 Lab 契约 | P0 / 2 | 能运行评分器并解释每个张量 shape。 |
| 1 | stable softmax | P0 / 3 | 通过行归一化和极端数值隐藏测试。 |
| 2 | 缩放点积 attention | P0 / 3 | 通过 Q/K/V 与权重、输出 shape 测试。 |
| 3 | causal mask 和单头 self-attention | P0 / 3 | 通过未来 token 不可见、边界和无 NaN 测试。 |
| 4 | LayerNorm、FFN、残差和单层 block | P1 / 4 | 通过组合顺序、输入不变性与完整前向测试。 |

### 第 2 周：独立 demo 与复盘（P1）

| 任务 | 重要程度 / 难度 | 通过证据 |
| --- | --- | --- |
| 不看 Lab 答案，独立重写最小 Transformer | P0 / 4 | 单层、单头前向传播可运行，且可解释每个模块。 |
| 字符级数据、embedding、输出层 | P1 / 2 | 输入、目标和词表维度一致。 |
| 交叉熵、反向传播与参数更新 | P0 / 4 | loss 下降，能解释训练信号。 |
| 字符生成与失败复盘 | P1 / 3 | 生成样例；记录失败现象、原因假设和验证办法。 |
| 后续方向选择 | P2 / 1 | 只在复盘后决定 multi-head、PyTorch、RAG 或更大项目。 |

## 成功标准

- 能不看答案解释 attention 权重、缩放、causal mask、残差、LayerNorm 和 FFN 的输入、输出与作用。
- Lab 的隐藏核心测试全部通过，且能根据评分反馈定位并修正至少一个真实错误。
- 能独立完成极小字符级 next-token prediction demo，并观察到 loss 下降和生成结果。
- 最终复盘清楚区分：已理解机制、尚未理解机制、下一个值得做的大项目。

## 风险控制

| 风险 | 控制方式 |
| --- | --- |
| 为通过测试而猜答案 | 保持核心输入与期望输出隐藏，只暴露失败类别与思考提示。 |
| 卡在错误却不知从何查 | autograder 按数值、shape、mask、组合顺序分类反馈。 |
| 过早看参考实现 | 第 2 周独立 demo 前不提供参考解。 |
| 范围膨胀到 RAG 或框架 | 复盘前不进入下一主题。 |
